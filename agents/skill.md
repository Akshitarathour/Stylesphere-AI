# StyleSphere AI - Multi-Agent Skills Specification

## 1. Closet Agent
- **Description**: Manages `stylesphere.db` CRUD operations for wardrobe items.
- **Skills**: Add/Edit/Delete clothes, track usage logs, category grouping.

## 2. Image Recognition Agent
- **Description**: Multimodal vision parser for uploaded garments.
- **Skills**: Extract color hex, patterns (Solid/Striped/Floral), sleeve length, and fabric tags.

## 3. Weather & Occasion Agent
- **Description**: Contextual compliance router.
- **Skills**: Inject real-time weather constraints, layer recommendations, and map formality logic (Interview, Wedding, College).

## 4. Sustainability & Shopping Advisor Agent
- **Description**: Financial and eco-efficiency auditor.
- **Skills**: Calculate Cost-Per-Wear (CPW), flag duplicate tags, identify underutilized garments, and compute Wardrobe Utilization Index.

## 5. Packing & Preference Agent
- **Description**: Personalized minimalist logistics concierge.
- **Skills**: Enforce 5-4-3-2-1 travel rules, track user's historical upvotes to learn favorite color palettes.
